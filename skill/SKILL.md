# A股短线分析与回测

## 准备
1. 获取代码：克隆 `https://github.com/omerorn001-sudo/a-share-short-term`，或者解压技能附件 zip 到 `/data/a-share-short-term`。
2. 在 `/data/a-share-short-term` 中安装依赖：`pip3 install -q akshare pandas numpy PyYAML`。
3. 所有命令都在该目录下运行：`python3 -m ashare.cli <命令>`。

## 按请求选择流程

| 用户请求 | 执行 |
|---|---|
| 预测/判断今日大盘 | `market` + `boards`，再用 web_search 补充隔夜外盘、周末政策、地缘事件 |
| 短线选股 | `market` 判断仓位 → `boards` → `screen --top 20` |
| 持仓该不该卖 | `check 代码:成本价 ...` |
| 验证策略/参数 | `study`（信号本身）→ `backtest` → `sweep --grid ...` |

## 规则
- **数据时点**：盘中运行时，最后一根K线是未收盘数据。必须向用户说明这一点；收盘后的结论最可靠。
- **大盘预测**：给情形和概率（例如震荡偏强、冲高回落、走弱下探），附支撑和压力位，不给确定性结论。每一个外部事实都要加引用。
- **回测汇报**：必须报告成交笔数、胜率、盈亏比、利润因子、最大回撤、年化收益。利润因子 < 1 时，要明确说明"该参数无正期望"，不能美化结果。
- **改参数**：用 `sweep --grid 键=值1,值2`，键名见 `config.yaml`（例如 `exit.stop_loss`、`exit.exit_below_ma`、`strategy.vol_mult`）。
- **股票池**：`--universe sample|hs300|zz500|zz1000|文件`。先用 `--limit 20` 试跑，再跑全量；首次下载较慢，之后走 `data/cache` 缓存。
- **接口失败**：东方财富接口在云环境常被拒，系统会自动回退到新浪、腾讯、同花顺。快照回退后没有量比和市值，需要说明 `screen` 的初筛会因此变宽。
- **结尾提示**：每次输出末尾加一句"不构成投资建议"。

## 输出格式
1. 结论一句话（例如：评分50分，建议3-5成仓位）
2. 关键数据表
3. 依据与风险（2-4条）
4. 下一步建议（可选）

## 局限（汇报时按需说明）
- 回测使用当前成分股，存在幸存者偏差。
- 权益曲线不含持仓浮亏。
- 主力资金流、筹码分布不纳入量化结论。
