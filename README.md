# A股短线选股与回测系统（a-share-short-term）

把"大环境 → 板块 → 个股 → 买点 → 卖点 → 风控"这套短线框架落成可执行、可回测的代码。行情数据优先用内置的东方财富网页接口爬虫（`ashare/eastmoney.py`，与 quote.eastmoney.com 同源），拿到量比、换手率、流通市值和板块主力净流入；失败时依次回退 AKShare 东财、新浪、腾讯、同花顺。全部带本地缓存。

> ⚠️ 仅供研究学习，不构成投资建议。默认参数是经验值，必须用回测校准。

## 功能

| 命令 | 作用 | 对应框架 |
|---|---|---|
| `market` | 大盘7维研判：指数趋势、两市成交额、涨跌停情绪、融资余额、龙虎榜机构席位、机构调研热度、板块广度 → 综合得分与建议仓位（`--simple` 为旧版0-100分） | 大环境 |
| `analyze` | 个股10维深度分析：趋势、突破量能、卖出预警、主力资金、融资、龙虎榜席位（机构/北向/游资）、机构调研（个股+所属行业）、板块强度、基本面事件 → 买/卖/观察结论、逐条理由、缺失维度说明、价位计划 | 个股 + 买卖点 |
| `boards` | 行业板块涨幅、涨跌家数、领涨股 | 板块 |
| `scan` | 初筛通过的**全部**股票全量分析：技术 5 条 + 资金 2 条（主力5日净流入、资金面综合分≥1：主力/融资/龙虎榜机构/机构持仓）+ 调研/板块/基本面 → 结论 | 个股 + 买点 |
| `screen` | 全市场快照初筛（市值/换手/量比/成交额）→ 日线技术复核 → 涨停连板标签 → 评分 | 个股 + 买点 |
| `check` | 持仓卖点体检：跌破均线、长上影、放量滞涨、量价背离、MACD 顶背离、RSI/KDJ 超买 | 卖点 |
| `backtest` | 事件驱动回测（T+1、涨停买不进、跌停卖不出、佣金印花税滑点、分档止盈、止损） | 验证 |
| `study` | 信号事件研究：信号后 1/3/5/10 日收益与胜率 | 验证信号本身 |
| `sweep` | 参数网格回测，比较不同止损/均线/阈值 | 校准参数 |

## 安装

```bash
git clone https://github.com/omerorn001-sudo/a-share-short-term.git && cd a-share-short-term
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## 用法

```bash
python -m ashare.cli market                       # 今日大环境评分
python -m ashare.cli boards --top 10              # 板块强度
python -m ashare.cli screen --top 20 --deep 5     # 选股，并对前5只做深度分析（盘后最准确）
python -m ashare.cli analyze 601519 002487        # 个股深度分析（买入视角）
python -m ashare.cli analyze 600519:1250          # 持仓深度分析（卖出视角，代码:成本价）
python -m ashare.cli check 600519:1250 300750:300 # 持仓体检（代码:成本价）

# 回测与验证（首次会下载并缓存日线）
python -m ashare.cli backtest --start 20210101 --universe hs300
python -m ashare.cli study    --start 20210101 --universe zz500
python -m ashare.cli sweep    --start 20210101 --universe sample \
    --grid exit.exit_below_ma=0,5,10 exit.stop_loss=0.05,0.07
```

`--universe` 可选 `sample`（内置 40 只）、`hs300`、`zz500`、`zz1000`，或每行一个代码的文本文件。结果 CSV 保存在 `reports/`。

## 策略规则（默认，见 `config.yaml`）

**买入**（T 日收盘判定，T+1 开盘成交）：收盘创 20 日新高；成交量 ≥ 前 5 日均量 1.5 倍；站上 MA5，且 MA5 > MA10 > MA20；偏离 MA5 ≤ 7%；开盘涨停则放弃。

**卖出**（优先级从高到低）：
1. 硬止损：盘中跌破成本 −7%
2. 分档止盈：+10% 卖 1/3，+20% 再卖 1/3
3. 收盘信号，次日开盘执行：持有满 10 天 / 从最高收盘回撤 8% / 收盘跌破 MA5 / 3 天未盈利

**组合**：最多 5 仓，每仓 1/5，同日信号按量比排序。

## 示例结果（仅说明工具用法）

内置 40 只大盘股，2023-01 至 2026-10，默认参数：321 笔，胜率 31%，盈亏比 2.08，利润因子 0.94，年化 −2.8%，最大回撤 −21%。

结论：放量突破策略在大盘蓝筹上没有正期望，胜率太低。这正说明框架必须先验证再使用。可以换成中小盘股票池（`zz1000`），叠加 `market` 评分过滤，或者调整参数再测。

## 多维度分析的判定规则

每个维度给出 🟢利多 / 🔴利空 / ⚪中性 / ⚫无数据 和 −2~+2 分。没有发生的事件也会写明，例如"近30个交易日未上龙虎榜""近90天无机构调研，所属行业近30天被调研N次、排第M"。

- **买入**：触发放量突破，个股得分 ≥ +2，且大盘得分 ≥ −2 → 小仓位买入；有信号但其他维度弱 → 谨慎买入或观察
- **观察**：没有信号，但多维度偏多 → 等待放量突破触发价
- **卖出（带成本价）**：亏损达到止损线 → 卖出；跌破MA5且有顶部信号 → 卖出或减仓；盈利 ≥10% → 分批止盈；多维度得分 ≤ −3 → 减仓
- 两融、龙虎榜为 T+1 数据（不含当天）；调研反映中长期关注，只作方向参考

## 已知局限

- **幸存者偏差**：成分股用的是当前名单，回测结果会偏乐观。严谨研究应使用历史成分并包含退市股。
- **权益曲线**按已实现收益计算，持仓期间的浮亏没有计入回撤。
- 资金流、筹码分布等口径不一，未纳入回测；龙虎榜、情绪数据只用于盘后参考。
- 东财接口对云服务器 IP 间歇性返回 502 或断开连接。爬虫会自动轮换节点、多轮重试，全市场快照约需 1–5 分钟，缓存 15 分钟；家用网络通常只需十几秒。连续失败才回退新浪，回退后没有量比和市值。

## 每日游资动向（龙虎榜）

```bash
python -m ashare.cli youzi                 # 最新上榜日（盘后约 17:00–18:30 更新）
python -m ashare.cli youzi --date 2026-10-12 --stats 20
```

- 抓东财龙虎榜买卖前 5 营业部，按 `ashare/youzi_seats.yaml` 把营业部映射为游资外号（章盟主、作手新一、拉萨天团、量化打板……），另标出机构专用、北向、外资席位。
- 输出：各游资买卖清单、个股游资合力榜、机构净买/净卖前 5、未识别大额席位（便于补充映射）、近 N 个上榜日各游资“战绩”（上榜后次日/2日/5日涨跌）。
- 结果保存在 `reports/youzi/日期.md` 和 `日期_seats.csv`。
- `.github/workflows/youzi.yml` 每个交易日北京时间 18:40、20:10 自动运行并把报告提交到仓库，也可在 Actions 页手动运行并指定日期。
